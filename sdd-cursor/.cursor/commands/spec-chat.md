# /spec:chat

## 定位

流程外的自由讨论。**不写 research.md / proposal.md / design.md，不推进任何阶段。**

## 纪律

- 每个建议过四问：为什么需要（不解决什么问题）/ 何时有利（锚定具体场景，不是"更优雅"）/ 代价（说不出代价 = 没想清楚）/ 能不能砍（砍掉无影响就别写）
- 偏好类决策给 2-4 选项 + 推荐项在前 + 一行理由（AskUserQuestion）
- 用户决定方向后，引导进对应命令：
  - 方向清楚、要正式化 → /spec:research "<方向>" 或直接 /spec:propose
  - 需求还不清 → 继续聊，聊到能写出 goal 为止
