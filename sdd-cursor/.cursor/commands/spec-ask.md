# /spec:ask

## 两种模式

### 独立调用（交互式）

逐个 [TBD] 盘问，规则：
- 偏好类决策**必须** AskUserQuestion（2-4 选项，推荐项在前 + 一行理由）
- 事实类先查证据，查不到再问
- 最多一次 4 个问题；>4 个拆分多轮收窄
- 每个问题自包含：① 决策/动作一行 ② 理由（影响什么/不做的代价）③ 每个选项的后果
  **检验：用户不用追问就能决定**
- 不确定是事实类还是偏好类 → 按偏好类处理

### workflow 编排内（auto-triage，不打断）

- 事实类 → 查证据定
- 可逆偏好 → 自决 + `auto` 标记
- 不可逆/产品语义 → 自决 + `escalated` 标记（gate 置顶展示，默认生效可推翻）
- 每个自决过四问：为什么需要 / 何时有利（锚定具体场景）/ 代价 / 能否砍掉（砍掉无影响就不写）
- "不做/最小实现"永远是候选

## 产出

- 更新 research.md：`## Open [TBD]` 清空 → 移入 `## Decided`（DEC-N 编号 + 理由 + 标记）
- 汇报：消解了哪些、各自依据（证据或默认值 + 可逆性）
